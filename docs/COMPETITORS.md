## Что рынок считает обязательным

| Норма рынка | VINGO сегодня |
|---|---|
| Заказ-наряд как центральный документ: работы + запчасти, статус | **Есть с 16.09.2026** — работы, приём машины, печать по ПП РФ № 780 |
| База клиентов с историей по каждой машине | Клиенты и гараж есть; истории обращений по машине как экрана нет |
| Проценка хотя бы по нескольким поставщикам | Слой есть; на проде поставщики в демо — нет ключей ABCP/Emex |
| Схемы узлов с выбором позиции | Есть: схема, выноски, «пришлите номер со схемы» в боте, позиция в вебе |
| Напоминания клиенту о ТО | Регламент ТО только командой `/то` в боте; уведомлений клиенту нет |
| Онлайн-запись | Нет — осознанно, не задача приёмщика |
| Складской учёт | Нет — осознанно, малый сервис |
| Выгрузка в 1С | Нет |
| Мобильный доступ | Есть: Telegram-бот и Expo-приложение |
| Заявка в свободной форме и ответ за минуты | Есть: жаргон, голос, фото шильдика, «Спросить эксперта» |
| Кассовый чек 54-ФЗ | Через ЮKassa при подключённой кассе; на проде не включено |

## Где VINGO выигрывает

- **Честность про данные.** Демо-цены помечены, источник в ответе (`source.demo`). У ботов
  конкурентов (VINOK, Zapfi, ZapGPT) мультипоставщицкая проценка с реальными ценами публично
  не подтверждена — либо одна точка, либо цена не раскрывается. Ниша «VIN → OEM → живая
  проценка у независимых поставщиков → заказ» открыта.
- **Человек в цикле без выдумки.** «Спросить эксперта» отвечает каталожными номерами от
  оператора, модель номера не изобретает. У Ta-Dam то же, но за подписку 4 890+ ₽.
- **Граница между машинами.** Сессия бота и веб-поиск сбрасываются при смене VIN — схема и
  кнопки прошлой машины не продолжают разговор. У ботов конкурентов этого не видно.
- **Один бэкенд на три канала** (веб, бот, мобильное): подбор, корзина и заказ-наряд одни и
  те же.

## Где VINGO отстаёт

1. **Поставщики клиента.** Ta-Dam и STOCRM работают на аккаунтах поставщиков самого СТО.
   У VINGO это следующий шаг — `SupplierAccount` на организацию (ROADMAP, п. 1a).
2. **Дефектовка → смета → одобрение клиентом** одной цепочкой (Tekmetric, AutoLeap): фото
   с подъёмника, ссылка клиенту, согласие на допработы — п. 14 ПП № 780 требует согласия на
   допработы, и это можно сделать нативно: ссылка «согласовать» из заказ-наряда.
3. **История по машине** одним экраном: все заказ-наряды, пробеги, что менялось.
4. **Напоминания клиенту о ТО** из пробега и регламента (регламент уже есть).
5. **Выгрузка документов в 1С / бухгалтерию** — нужна СТО-юрлицам (402-ФЗ, ст. 9).
6. **Нормо-часы** для автосборки сметы — у Tekmetric из VIN за 30 секунд. В России открытой
   базы нормо-часов нет; сначала — свои шаблоны работ на организацию.

## Как это ложится в дорожную карту

Ближайшее (закрывает разрыв с Ta-Dam/STOCRM при нуле стоимости данных): аккаунты
поставщиков на организацию → история заказ-нарядов по машине → согласование допработ по
ссылке → напоминания о ТО. Дальше — шаблоны работ и выгрузка в 1С. Подробно — в
[ROADMAP.md](ROADMAP.md).
