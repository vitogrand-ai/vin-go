# Источники каталожных данных — обзор 16.09.2026

Что есть на рынке под задачу «VIN → OEM-номер → схема узла», что из этого бесплатно, что
легально и что стоит подключать следующим. Обзор собран 16.09.2026 по открытым страницам
вендоров; всё, что помечено «не проверено вживую», — по описанию на сайте, а не по живому
вызову API. Живой вызов — следующий шаг перед любой оплатой.

Что уже подключено боевыми адаптерами: parts-catalogs.com (мировой OEM, русский из
коробки) и 17vin (китайский EPC). Что именно каждый адаптер обязан вытащить из источника —
в [CATALOG_ADAPTERS.md](CATALOG_ADAPTERS.md). Здесь — про то, *откуда* брать данные.
Что из этого лежит в свободном доступе (витрины магазинов, бесплатные справочники, заводские
PDF, форумы) — в [FREE_CATALOGS.md](FREE_CATALOGS.md).

## Коротко

- **Бесплатных каталогов деталей нет.** Единственный легально бесплатный API в нише —
  NHTSA vPIC, и он только расшифровывает VIN (марка/модель/год/двигатель) для машин рынка
  США. OEM-номеров, кроссов и схем он не отдаёт. Всё остальное «бесплатное» — короткий триал
  или горстка тестовых VIN.
- **Китайские марки** (главная дыра пилота: Chery, Great Wall у 17vin пустые) закрываются
  дешевле всего у *того же* parts-catalogs — у них появился отдельный тариф «Chinese
  Parts-Catalogs». Тот же REST API, тот же адаптер, нужен только новый ключ. Независимый
  запасной кандидат — GOODVIN.
- **Российские марки** (Lada/UAZ/GAZ): официального API у заводов нет. Кандидаты —
  ilcats.ru (документированный API, подключение через поддержку) и VINPIN (браузер/1С,
  REST не подтверждён).
- **Не подключать**: скрейперы чужих сайтов (Amayama через parse.bot), TecDoc через
  казахстанского партнёра (обход санкционного ограничения — юридический риск для
  российского юрлица), просмотровые сайты без API (epcinfo, japancats, elcats).

## Рекомендуемый порядок действий

1. **Спросить у менеджера parts-catalogs ключ на тариф «Chinese Parts-Catalogs»** и прогнать
   его на VIN из корзины случаев, где 17vin пуст: Chery Tiggo 5x `LVVDB21B9RC095635`,
   Great Wall Wingle `LGWDBE191LB631118`. Кода это не требует: `FallbackCatalogProvider`
   уже умеет цепочку декодеров, а `CachingCatalogProvider` бережёт квоту.
2. **Параллельно взять 3-дневный тест GOODVIN** на тех же VIN и сравнить: есть ли схемы с
   выносками и русские названия. Перед оплатой — прямой вопрос о лицензии данных.
3. **Написать в ilcats.ru** за ценой API вне пакета PARTS-SOFT и списком российских марок;
   написать в VINPIN, есть ли у них программный интерфейс.
4. **vPIC** подключать только когда появится американский рынок — как бесплатный первый шаг
   цепочки декодирования для VIN с первой цифрой 1, 4, 5.
5. **Не тратить время** на Laximo, TecDoc-через-Казахстан, скрейперы и просмотровые сайты.

## Дополнение 23.09.2026: Трейд Софт и марки без VIN

Повод: заказчик узнал, что «у Трейд Софт и других есть каталоги и схемы», и спросил, где их
взять. Проверено по открытым страницам, ключевые утверждения перепроверены вторым проходом по
ссылкам. Живых вызовов не было.

- **Трейд Софт — это и есть наш вендор.** Parts.Index / Parts-Catalogs — продукт Tradesoft
  (tradesoft.ru/parts-index/parts-catalogs), то есть тот самый parts-catalogs.com, который уже
  подключён. На parts-catalogs.com/eu: 2 дня бесплатного демо, OEM-тарифы €229–€1299/мес
  (1000–10000 запросов). Остальное «у Трейд Софт» — их платформа для магазинов запчастей, куда
  встраиваются чужие каталоги (Laximo, ACAT, ilcats) так же, как у ABCP и PARTS SOFT.
- **Откуда у каталогов данные, не раскрывает никто**: ни Tradesoft, ни ACAT, ни Laximo, ни
  GOODVIN (он прямо пишет, что «собирает у дилеров»). Перед оплатой нового источника — прямой
  вопрос о лицензии.
- **Марки без VIN у parts-catalogs** (таблица вендора — в [CATALOG_ADAPTERS.md](CATALOG_ADAPTERS.md)):

- **Серые, не подключать**: tecdoc.ru (продаёт TecDoc как «параллельный импорт», а базы
  данных под параллельный импорт не подпадают), vinsearch.online (посуточный доступ к
  дилерским EPC без объяснения, откуда он), любые «скачать EPC» с торрентов и файлообменников.
  **PartsAPI.ru** рекламирует «TECDOC 2025Q4» без лицензии TecAlliance, которая ушла из РФ в
  2022–2023. Адаптер `partsapi-provider.ts` готов, но ключ под него не продлевать, пока вендор
  не покажет, откуда данные.
- **Порядок проверки:** тестовый доступ ACAT → прогнать через него машины корзины `catalog:cases`,
  которых нет у parts-catalogs (Jaguar, плюс УАЗ, Citroen, Nissan, если такие VIN появятся),
  и проверить главное: есть ли схема узла с номерами позиций, а не только список артикулов.
  GOODVIN за 5 000 ₽ — только если в пилоте появится GAC.

## Что истекает

- Тестовый ключ parts-catalogs (100 VIN, привязан к IP VPS) — **до 19.09.2026**.
- Тестовый аккаунт 17vin — **до 19.09.2026**.

После этих дат прод молча перейдёт в «ничего не найдено» по всем машинам, кэш `vin_decodes`
лишь отсрочит это для уже искавшихся VIN. Проверка после продления —
`bun run --cwd backend smoke:live -- http://<адрес>`.

## Правила, которые не меняются

- Модель не выдумывает OEM-номера и не связывает название с номером сама — только переводит
  строки, пришедшие из каталога.
- Каталоги и поставщики до конца пилота — только чтение: никаких заказов, платных заявок,
  передачи данных им (`no-supplier-writes.test.ts`).
- Ключи доходят до сети и журналов только через `safeUrl` (`provider-secrets.test.ts`).
